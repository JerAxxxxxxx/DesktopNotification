# 下班啦

工作有时，生活也是。

## 打开应用

- 直接双击 `Offwork-<版本号>-x64-portable.exe`。
- 需要 Windows x64 和 Microsoft Edge WebView2 Runtime。系统缺少 WebView2 时，需要先安装该运行环境。

## 设置提醒

设置下班时间、停止提醒时间、重复间隔、提醒日期和文案，点击「保存设置」。点击「测试提醒」预览已保存的设置。在测试卡片里点暂停或稍后提醒，只会关闭预览。正式提醒到点时会接替预览卡片。

默认是周一至周五，18:00 开始，21:00 停止，每 10 分钟提醒一次。不自动识别节假日和调休，不支持跨午夜时段。

## 节假日倒计时

主界面显示最近一个假期。点击展开可查看 2027 年七个假期的倒计时、日期和放假天数。按北京时间倒数到放假首日，假期期间显示「放假中」。数据内置，无需联网。此功能只显示假期信息，不改变下班提醒。

## 桌面倒计时

默认显示在桌面右上角，每秒更新。用左键按住卡片可拖动；点「×」可隐藏，从设置里的「桌面悬浮窗」或托盘右键菜单可以重新显示。应用会记住是否显示。

双击计时区域可打开设置。倒计时平时用紫色，下班前 30 分钟切换为青绿色，下班后切换为暖橙色。

到下班时间切换为「已加班」，从零开始累计，到次日重置；休息日显示「今天休息」。暂停、推迟或到点停止提醒都不会影响计时。

## 提醒弹出后

卡片默认显示 15 秒后自动收起，后续仍按设置的间隔提醒。

- 「今天不再提醒」：今天停止提醒，明天自动恢复。
- 「N 分钟后提醒」：按你设置的间隔再提醒。
- 右上角关闭：只关闭当前卡片，后续仍会提醒。

关闭设置窗口后，程序仍在右下角托盘运行。单击托盘图标打开设置；右键菜单可暂停、恢复或彻底退出。

「登录后自动启动」默认关闭，按需开启。所有设置和今日暂停状态仅保存在这台电脑。

电脑关机或睡眠时不提醒；程序不会主动唤醒电脑。
